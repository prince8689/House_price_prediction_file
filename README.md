# House Price Prediction System

## Description
A full-stack web application that predicts house prices based on user-provided inputs.  
The project demonstrates frontend–backend integration and follows clean project structure suitable for internship-level development.

## Tech Stack
- Frontend: HTML, CSS, JavaScript
- Backend: Node.js, Express.js
- Database: MongoDB 
- Tools: Git, GitHub

## Features
- User-friendly interface for entering house details
- Backend API to process data and return predicted price
- Secure environment configuration using environment variables
- Modular and scalable project structure

## Project Structure
-frontend/ -> User interface
-backend/ -> Server and APIs
-README.md -> Project documentation


## How to Run the Project Locally
1. Clone the repository
2. Run `npm install`
3. Create a `.env` file using `.env.example`
4. Start the server using `npm start`
